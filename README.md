# Diabetes Risk Analysis

## Objective
This project investigates which health factors are most strongly associated with diabetes risk using a publicly available diabetes dataset.

## Dataset
The analysis uses the Pima Indians Diabetes dataset, containing health-related variables such as glucose level, BMI, blood pressure, age and diabetes outcome.

## Methods
- Data loading and inspection
- Missing value checks
- Descriptive statistics
- Correlation analysis
- Visualisation using Python and matplotlib

## Key Findings
The analysis found that glucose level showed the strongest correlation with diabetes outcome. BMI and age also showed positive associations with diabetes risk.

## Tools Used
- Python
- pandas
- matplotlib

## Why This Project Matters
This project demonstrates healthcare data analysis skills, including data cleaning, statistical exploration, and communicating insights from biological/clinical datasets.
